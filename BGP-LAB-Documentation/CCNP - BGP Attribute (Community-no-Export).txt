CCNP - BGP Attribute (Community-no-Export)


Konfigurasi Router1

hostname Router1
int fa0/0
no sh
ip add 12.12.12.1 255.255.255.0

int lo0
ip add 1.1.1.1 255.255.255.255

router bgp 1
bgp confederation identifier 123
bgp confederation peers 2
neighbor 12.12.12.2 remote-as 2
net 1.1.1.1 mask 255.255.255.255 


access-list 1 permit host 1.1.1.1   
route-map NO-EXPORT permit 10
match ip address 1
set community no-export 
route-map NO-EXPORT permit 20

router bgp 1
neighbor 12.12.12.2 route-map NO-EXPORT out
neighbor 12.12.12.2 send-community
