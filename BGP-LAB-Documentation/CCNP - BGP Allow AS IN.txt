CCNP Enterprise - BGP Allow AS IN


Konfigurasi Router 1

hostname Router1
int fa0/0
no sh
ip add 12.12.12.1 255.255.255.0

int l0
ip add 1.1.1.1 255.255.255.255

router bgp 65000
nei 12.12.12.2 remote-as 2
net 1.1.1.1 mask 255.255.255.255


debug ip bgp updates
