Konfigurasi Static Routing dan Redistribute pada R1-PE

ip route vrf Malaysia-Kiri 4.4.4.4 255.255.255.255 192.168.100.2          
ip route vrf Indonesia-Kiri 5.5.5.5 255.255.255.255 192.168.100.2 

 
router bgp 123 
address-family ipv4 vrf Malaysia-Kiri  
redistribute static  
redistribute connected  
 
 
address-family ipv4 vrf Indonesia-Kiri 
redistribute static  
redistribute connected  
exit
