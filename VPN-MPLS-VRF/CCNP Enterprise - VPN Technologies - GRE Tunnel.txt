Konfigurasi Router 2

int tun23
ip add 172.16.10.1 255.255.255.252
tunnel source fa0/0
tunnel destination 13.13.13.3

Konfigurasi Router 3

int tun23
ip add 172.16.10.2 255.255.255.252
tunnel source fa0/0
tunnel destination 12.12.12.2


Verifikasi Tunnel.
show int tun23 | i protocol


Lanjut Routing EIGRP

Konfigurasi Router2

router eigrp 23
network 172.16.10.1 0.0.0.0
network 2.2.2.2 0.0.0.0
no auto-summary
exit


Konfigurasi Router3

router eigrp 23
network 3.3.3.3 0.0.0.0
network 172.16.10.2 0.0.0.0
no auto-summary

Verifikasi Routing pada R2 dan R3

show ip route eigrp

Test ping
Router2#ping 3.3.3.3
Router3#ping 2.2.2.2


Verifikasi Traceroute lewat tunnel

Router2#traceroute 3.3.3.3 source 2.2.2.2
